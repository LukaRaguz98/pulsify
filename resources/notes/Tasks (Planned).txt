PULSIFY-62 — Pricing Plan Feature Audit & Gating Synchronization (v0.62.0)

Description
	Since the original Pricing Plans and Stripe integration (PULSIFY-29), Pulsify has expanded significantly with dozens of new modules, automations, Discord commands, analytics, security tools, and economy features. Many of these were introduced without being explicitly assigned to a subscription tier.
	This task performs a complete audit of every existing Pulsify feature, classifies each one into the appropriate pricing tier, synchronizes backend feature gating, updates the public pricing page, and ensures the billing experience accurately reflects the current product offering.
	The goal is to establish a single source of truth for feature availability and ensure all future features are pricing-aware by default.

Goals
	Audit every existing Pulsify feature and module
	Assign all features to an appropriate pricing tier
	Synchronize dashboard, backend, Discord commands, and pricing page
	Enforce feature gating consistently across the platform
	Prepare the pricing system for future feature releases

Non Goals
	No changes to pricing amounts
	No introduction of new subscription plans
	No implementation of new product features
	Focus exclusively on auditing, classification, and synchronization

Acceptance Criteria
	Every Pulsify feature has an assigned pricing tier
	Dashboard, backend, and Discord commands enforce identical feature gating
	Usage limits are applied consistently across all plans
	Public pricing page accurately reflects all available functionality
	Billing settings display correct feature availability
	Upgrade prompts are consistent throughout the platform
	Existing subscribers are handled without unexpected feature loss
	Internal documentation provides a single source of truth for future feature classification
