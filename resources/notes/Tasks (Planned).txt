PULSIFY-29 — Pricing Plans, Feature Gating & Payment System (v0.29.0)

Description
	Implement the complete Pricing and Subscription system inside Pulsify, including pricing plan management, feature access restrictions, subscription handling, and payment integration.
	The system should connect existing Pulsify functionality with subscription tiers and dynamically enable/disable features depending on the active user/server plan.

Goals
	Introduce functional subscription plans
	Monetize existing Pulsify systems/features
	Restrict features based on active plan
	Implement payment and billing infrastructure
	Prepare Pulsify for public SaaS launch

Tasks
	Pricing Plans System
		Implement pricing plan infrastructure
		Add supported plans:
			Free
			Pro
			Business
			Enterprise
		Add plan metadata/configuration system
		Add monthly/yearly billing support

	Feature Gating
		Connect existing Pulsify features to plans
		Restrict/enable features dynamically based on active subscription
		Add feature limitations such as:
			number of servers
			analytics retention
			AI moderation access
			ticket system limits
			automations limits
			giveaways limits
			advanced moderation tools
			custom branding
			multi-server management
			advanced analytics
			backup/restore access
			API access
		Add plan validation middleware/backend checks
		Prevent unauthorized access to premium features

	Dashboard Integration
		Add current subscription display
		Add plan usage/progress indicators
		Display:
			active plan
			renewal date
			billing cycle
			feature usage
			feature limits
		Add upgrade/downgrade flows
		Add “locked feature” states inside the dashboard

	Payment System
		Implement payment provider integration
		Add secure checkout flow
		Add subscription creation/cancellation
		Add recurring billing support
		Add payment success/failure handling
		Add invoice/payment history
		Add webhook handling for subscription updates
		Add trial support/free trial handling

	Billing Management
		Create Billing settings page
		Add:
			payment method management
			invoice history
			billing details
			subscription management
			cancel/reactivate subscription
		Add usage-based warnings/notifications

	UX Improvements
		Add modern pricing UI/cards
		Add responsive billing pages
		Add animated upgrade prompts/modals
		Add loading/error/success states
		Add upgrade recommendations based on feature usage

	Security & Reliability
		Validate subscription state server-side
		Prevent client-side bypassing of premium features
		Add secure webhook verification
		Add billing audit logs/history
		Add fallback handling for failed payments

Acceptance Criteria
	Pricing plans function correctly
	Existing features are properly gated by plan
	Users only access features included in their plan
	Payment system processes subscriptions successfully
	Billing page displays correct subscription data
	Upgrade/downgrade flows work properly
	Premium feature restrictions are enforced securely
	UI remains responsive and visually polished
