PULSIFY-54 — Temporary Roles Tab & Expiring Permissions (v0.54.0)

Description
	Upgrade the existing Server > Roles view by introducing a dedicated Temporary Roles tab that allows administrators to assign, manage, and monitor roles with automatic expiration.
	Temporary Roles should integrate with existing Pulsify systems such as Economy, Marketplace, Giveaways, Events, Automations, Applications, and Moderation while providing a centralized interface for managing time-limited permissions.

Goals
	Extend the existing Roles management experience
	Reduce manual role maintenance
	Support temporary access and rewards
	Improve automation capabilities
	Centralize temporary role management

Tasks
	Roles View Upgrade
		Update:
			Server > Roles

		Add new tab:
			Temporary Roles

		Maintain consistency with existing Roles UI and navigation

	Temporary Role Assignments
		Allow administrators to assign temporary roles to members

		Display:
			member
			role
			assigned by
			assigned date
			expiration date
			remaining time
			assignment source

	Expiration Configuration
		Support:
			minutes

			days
			weeks
			months
			custom expiration date

		Examples:
			VIP for 30 days
			Event Access for 24 hours
			Giveaway Winner for 7 days
			Trial Moderator for 14 days

		Automatically:
			remove expired roles
			update role status
			log expiration events

			notify administrators if enabled
