PULSIFY-61 — Slash Commands Expansion & Full Feature Parity (v0.61.0)

Description
	Expand Pulse's slash command set so that core actions already implemented across Pulsify modules can also be executed directly from Discord, not only through the web dashboard.
	All commands must follow existing Pulse v2 embed styling and conventions established by /sync, /changelog, /balance, /pay, /leaderboard, /earn, /birthday, /alt-check, and /invites.
	Sensitive commands are restricted to Admin/Moderator permission levels, while safe read-only and self-service commands are available to all members.

Goals
	Bring dashboard-only actions to Discord via slash commands
	Achieve near-full feature parity between the web app and Discord
	Maintain strict permission separation between admin and member commands
	Ensure consistent Pulse v2 embed design across all commands
	Reduce the need to open the web app for common administrative tasks
	Keep command behavior synchronized with dashboard-configured settings and permissions
