PULSIFY-39 — Community Feedback & Testimonials System (v0.39.0)

Description
	Upgrade the existing feedback section on the Pulsify landing page by implementing a complete community feedback and testimonials system.
	Authenticated users should be able to submit feedback directly through the application, while the landing page automatically showcases the highest-rated community feedback to improve trust, transparency, and social proof.

Goals
	Improve landing page credibility
	Collect community feedback directly through Pulsify
	Showcase real user experiences
	Increase user engagement and trust
	Create a foundation for future testimonials and reviews

Tasks
	Feedback System
		Create a feedback submission system
		Allow authenticated users to submit feedback
		Support:
			title
			feedback message
			rating (1-5 stars)
		Prevent anonymous submissions
		Store author information

	Feedback Management
		Create feedback management functionality
		Allow users to:
			create feedback
			edit their own feedback
			delete their own feedback
		Prevent duplicate spam submissions
		Add validation and moderation safeguards

	Community Rating System
		Allow users to upvote helpful feedback
		Track:
			total votes
			rating score
			popularity score
		Prevent vote manipulation
		Prevent self-voting

	Landing Page Improvements
		Replace the current static feedback section
		Display real community feedback
		Show the Top 3 highest-rated feedback entries
		Display:
			author
			rating
			feedback message
			date submitted
		Add smooth carousel/grid layout
		Ensure responsive mobile experience

	Feedback Discovery
		Add feedback listing page/modal
		Allow viewing all community feedback
		Add:
			search
			sorting
			filtering
		Support sorting by:
			highest rated
			newest
			most helpful

	User Profile Integration
		Associate feedback with authenticated users
		Display Discord avatar and username where appropriate
		Handle deleted users gracefully

	Moderation
		Allow feedback removal by administrators
		Add report functionality
		Add visibility controls
		Prevent abusive content

	UX Improvements
		Add modern testimonial cards
		Add animated rating displays
		Add loading/error/empty states
		Add feedback success confirmations
		Improve overall landing page presentation

Acceptance Criteria
	Authenticated users can submit feedback
	Feedback is stored and displayed correctly
	Users can rate/upvote feedback
	Top 3 highest-rated feedback entries appear on the landing page
	Static testimonials are replaced with real community feedback
	Moderation controls function correctly
	UI remains responsive and visually polished
	Feedback system improves landing page trust and social proof
