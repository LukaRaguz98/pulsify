PULSIFY-31 — Discord Bot Update & Release Visibility System (v0.31.0)

Description
	Implement a Discord bot update and version visibility system for Pulse that allows users and administrators to easily see the current bot version, latest changes, 	release notes, and update status directly from Discord.
	The system should improve transparency, make Pulse feel more polished, and connect Discord bot updates with the public Pulsify Release Notes page.

Goals
	Improve Pulse bot update communication
	Add version visibility inside Discord
	Connect bot updates with Pulsify release notes
	Improve user trust and product polish

Tasks
	Version Commands
		Add /version slash command
		Add /changelog slash command
		Add /release-notes slash command
		Display:
			current Pulse version
			latest release title
			release date
			short changelog
			link to full release notes

	Bot Update Embeds
		Create polished v2 embeds for version/changelog responses
		Use Pulse branding and consistent embed styling
		Add buttons:
			View Release Notes
			Open Dashboard
			Invite Pulse
		Add fallback/error embeds if release data is unavailable

	Release Notes Integration
		Connect bot release commands with Pulsify release notes data
		Allow latest release info to be fetched dynamically
		Add support for manual/static fallback release data
		Ensure release notes link points to public website

	Startup Version Logging
		Log Pulse version on bot startup
		Log connected guild count on startup
		Log loaded commands count
		Add clear startup success/failure output

	Admin Update Notification
		Add optional update announcement command for admins
		Allow posting latest update embed into configured announcements channel
		Add permission checks for update announcement usage

	UX & Consistency
		Ensure all update/version embeds match Pulse design language
		Add clear wording for MVP/early access status
		Add loading/error/success handling
		Add command cooldowns to prevent spam

Acceptance Criteria
	/version displays current Pulse version correctly
	/changelog displays latest update summary
	/release-notes links to the public release notes page
	Bot update embeds are visually consistent with Pulse branding
	Startup logs show version, guild count, and command count
	Admins can optionally post update announcements to Discord
	Commands handle errors gracefully
