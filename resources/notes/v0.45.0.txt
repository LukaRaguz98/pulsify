**Pulsify v0.45.0 — Global Economy, Reputation & Progression**
Pulse Coins and reputation now follow members across every server running Pulse, while levels and XP stay server-specific. One identity, independent progression everywhere.

**A global currency: Pulse Coins**
- **One balance everywhere** — a single coin balance shared across all Pulse servers, earned by chatting, voice and commands with the same anti-spam rules as XP.
- **Bonuses & transfers** — level-ups, giveaway wins, milestones and onboarding all pay coins, and /pay sends them to another member: atomic and fully logged.

**Reputation, now global**
- **One trust score, everywhere** — the familiar 0–100 reputation is now computed from a member's activity across every Pulse server, shown the same on each.
- **Levels stay local** — XP and levels remain per-server; the profile spells out what's global (balance, reputation) and what's server-specific (level).

**Right in Discord**
- **/wallet & /pay** — check any member's global balance, reputation and recent activity, or send coins straight from chat.
- **/profile, upgraded** — now leads with the global reputation and coin balance alongside the server level.

**A new Economy dashboard**
- **Economy section** — a top-level category: Overview (circulation, trends, leaderboards and the full transaction ledger), Marketplace (coming soon) and operator-only Controls for granting or removing coins.
- **Global Pulse Profile** — each member's page shows their cross-server identity: balance, reputation, global rank and their level in every Pulse server.

**Pulsify for every member**
- **Members can sign in** — anyone in a Pulse server gets a read-only dashboard (profile, reputation, leaderboards, statistics, economy, events, giveaways, announcements); management stays admin-only and is enforced server-side.
- **Leaderboards & Member View** — boards now rank by global reputation alongside level, XP and activity, and operators can preview the dashboard exactly as members see it.

**Built to scale**
- **Atomic & live** — balance changes and transfers run through race-safe functions and update in real time everywhere, laying the groundwork for shops, inventories and marketplaces.

This is the first step towards a connected Pulse ecosystem where members earn, build reputation, and carry their identity across every community.
