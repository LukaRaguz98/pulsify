PULSIFY-28 — Release Notes Page & Community Roadmap Synchronization (v0.28.0)

Description
	Implement a dedicated Release Notes page for the public Pulsify website and improve the Community page by dynamically organizing tasks/features into Shipped, In 	Progress, and Planned sections.
	The goal is to improve transparency, communicate development progress, and create a more professional SaaS/community experience for users following Pulsify 	development.

	Improve communication with the community
	Showcase active development progress
