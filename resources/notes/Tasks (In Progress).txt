PULSIFY-31 — Changelog Command & Update Existing Commands (v0.31.0)

Description
	Implement a /changelog [version] slash command for Pulse that allows users to view release notes and version information directly from Discord and update existing commands.
	The command should provide an easy way to view the latest updates, improvements, and fixes without leaving Discord while remaining synchronized with Pulsify release notes.

Goals
	Improve update visibility inside Discord
	Allow users to access release information quickly
	Connect Discord with Pulsify Release Notes
	Improve transparency around new features and changes
	Update existing commands

Tasks

	Slash Command
		Add /changelog [version] command
		Add optional version parameter
		If a version is specified:
			Display release information for the requested version
		If no version is specified:
			Display the latest available release

	Changelog Data
		Create changelog storage structure
		Store:
			version number
			release title
			release date
			features
			improvements
			fixes
		Prepare structure for future releases

	Embed Design
		Create dedicated changelog embed design
		Display:
			version number
			release date
			categorized changes
			release notes link
		Use Pulse v2 embed styling
		Ensure mobile readability

	Error Handling
		Handle unknown versions gracefully
		Display friendly error messages
		Suggest latest version when requested version is unavailable

	Release Notes Integration
		Add button linking to Pulsify Release Notes page
		Ensure version numbers match website release notes
		Prepare support for future dynamic changelog synchronization

	UX Improvements
		Add command cooldown
		Add loading state while fetching changelog data
		Ensure consistent Pulse branding
		Optimize long changelogs for Discord embed limits

Acceptance Criteria
	/changelog displays the latest release
	/changelog [version] displays the requested release
	Unknown versions return a friendly error message
	Release notes link works correctly
	Embed follows Pulse design standards
	Changelog data is easy to maintain for future releases
