PULSIFY-56 — Self-Assign Roles, Button & Select Role Menus (v0.56.0)

Description
	Implement a Self-Assign Roles system that allows administrators to create interactive role menus where members can assign or remove roles themselves using Discord buttons or select menus.
	The system should replace the traditional reaction-role approach with a modern Discord Components experience while maintaining compatibility with future role management features.

Goals
	Reduce administrator workload
	Allow members to manage their own community roles
	Improve onboarding and personalization
	Replace external reaction role bots
	Integrate with existing Roles module

Tasks
	Roles View Upgrade
		Update:
			Server > Roles

		Add new tab:
			Self-Assign Roles

		Maintain consistency with existing Roles UI and navigation

	Role Menu Builder
		Allow administrators to create role menus

		Configure:
			menu title
			description
			target channel
			menu message
			menu type

		Support:
			Buttons
			Select Menu

	Role Assignment
		Allow members to:
			assign roles
			remove roles
			switch roles

		Support:
			single selection
			multiple selection
			required roles
			mutually exclusive roles

	Role Categories
		Support role menus for:
			Game Roles
			Notification Roles
			Platform Roles
			Language Roles
			Region Roles
			Interest Roles
			Color Roles
			Custom Categories

	Customization
		Configure:
			emojis
			button styles/colors
			role descriptions
			role ordering
			maximum selections
			default selections where applicable

	Preview
		Add live preview before publishing
		Preview both:
			Button layout
			Select Menu layout

	Discord Integration
		Publish role menus directly to Discord
		Automatically update published menus after edits
		Support message regeneration if deleted
		Handle Discord component limitations gracefully

	Role Menu Management
		Allow administrators to:
			edit menus
			duplicate menus
			enable/disable menus
			archive menus
			delete menus
			republish menus

		Display:
			menu status
			channel
			message ID
			creation date
			last updated
			total assignments

	Analytics
		Track:
			role assignments
			role removals
			most selected roles
			least selected roles
			active role menus
			menu interaction count

	Permissions & Validation
		Validate:
			role hierarchy
			Pulse permissions
			assignable roles
			duplicate roles within menus
			conflicting role configurations

		Display clear validation errors where required

	UX Improvements
		Add responsive role menu builder
		Add drag-and-drop role ordering
		Add search and filtering
		Add loading/error/empty states
		Add confirmation dialogs for destructive actions
		Use consistent Pulse v2 styling

Acceptance Criteria
	Self-Assign Roles tab is available under Server > Roles
	Administrators can create self-assign role menus
	Button and Select Menu modes function correctly
	Members can assign, remove, and switch roles successfully
	Role hierarchy and permission validation prevent invalid configurations
	Analytics accurately track role menu usage
	Published menus synchronize correctly with Discord
	UI remains responsive and visually polished
